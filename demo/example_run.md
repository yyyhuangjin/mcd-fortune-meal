## 6. 券无效时，核价怎么回（实测）

把今天还不能用的「11.9元麦辣鸡腿堡」塞进 `calculate-price`，接口直接拒绝：

```

券： 11.9元麦辣鸡腿堡
无券核价： 2250 分 = 22.5 元
用券核价：失败 → 此卡券不在使用日期内，请在有效期内来使用哦！
```

> 这一步是整套券逻辑的关键：**券面写着 11.9 元不算数，核价认了才算数**。
> 同一张券 10-26 10:30 起才生效，所以今天只能做「券预告」，不能承诺省钱。
