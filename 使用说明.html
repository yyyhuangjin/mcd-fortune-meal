1撕日历 · 领好运

吉今日宜吃麦
  • 进入页面是一张复古挂历，按住纸张下沿往下撕（或点底部红色按钮「撕开今日麦麦好运」自动撕）。
  • 撕开有真实阻尼与锯齿断口，先露出红黄包装层与「吉」认证章，再进入今日页。
  • 今天若逢凶日（黑道 / 破 / 闭），纸面盖「转运」章——凶日不慌，吃麦当劳转运。

2看黄历 · 选菜单

  • 今日麦麦黄历：宜忌、值日、星宿、喜神方位、天气全部为真实数据。
  • 天气决定取餐方式：雨天推荐外送、酷暑推荐冰饮、好天气推荐就近堂食/自取。
  • 页面顶部菜单已按推荐预先配好，可用加减号自选；「限定尝鲜」一键加购地区/时段限定新品；改动实时同步到开运小票。
  • 不满意推荐？点「换一份好运」切换方案，「换餐厅」可选最近门店。

3用优惠 · 一键下单

  • 系统自动比对全部可用优惠券，算出最划算的一单，实时核价后弹出确认。
  • 点「使用优惠 · 一键下单」→ 麦当劳 MCP 真实建单 → 跳麦麦出票机页。
  • 出票机「滋滋滋」打出开运小票；订单小票上有去支付（官方 App 收银台）、扫码付、查状态、15 分钟支付倒计时。
  • 付款回来页面自动核对：小票盖「已付」章、显示取餐码、记入「今日已吃」。

4保存小票 · 看月历

  • 出票页底部：保存小票导出 PNG、查看黄道月历翻整月吉凶与开运日。
  • 「今日已吃」卡片记录当天吃过的麦麦，第二天重开一张新日历。

5怎么跑起来

  • 上传的 almanac.html：自包含演示，浏览器直接打开即可玩撕日历、黄历、菜单、小票、月历（下单需本地服务）。
  • 完整体验：配置好麦当劳 MCP Token 后，pip install -r requirements.txt → python3 scripts/serve.py → 打开 http://127.0.0.1:8765。
  • Token 仅存服务端环境变量，不进入前端；配置模板见 mcp-config.example.json。
默认定位城市为演示数据装配时的定位；首次下单请以页面提示的真实门店与实时核价为准。

?常见问题

Q：黄历和宜忌是真的吗？
是。干支、值日、星宿、喜神方位来自真实黄历数据装配；宜忌文案由规则引擎按当日信息生成，非写死。

Q：下单是真的吗？会直接扣钱吗？
真实调用麦当劳 MCP 建单，但支付由你在麦当劳官方收银台完成，15 分钟未支付订单自动取消，不会误扣。

Q：凶日为什么也推麦当劳？
黄历讲究「诸事不宜」的日子更要讨彩头——黑道日自动切换「转运套餐」玩法。

Q：数据安全吗？
麦当劳 MCP Token 只在本地服务端持有，页面与演示文件中均不含任何密钥与个人地址信息。
